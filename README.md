# داتام‌پوی — پایشگر پیدا کردن پروژه
ایده، تولید و خلق: برهان مهرگان

نسخه ۱.۲.۰ — ظاهر کاملاً بازطراحی‌شده (تم روشن، کارت‌محور) با ۴ تب:
داشبورد، آمار، ارتباط با کارفرما، تنظیمات — به‌همراه فوتر ثابت شامل
حق کپی‌رایت، کد ملی جزئی‌نمایش‌داده‌شده، شماره نسخه و تاریخ شمسی روز.

اسکلت کامل اپلیکیشن دسکتاپ (Electron) برای جست‌وجوی پروژه‌های ساختمانی
در استان‌های تهران، البرز و مازندران، اولویت‌بندی سازه وافل / تاپ‌داون،
و ارسال پیام سریع واتساپ/بله به مسئول پروژه.

## چرا الان قابل اجرا نیست بدون کار شما
من به اینترنت زنده و به حساب‌های کاربری/اشتراک سایت‌ها (مثل سازه جو) دسترسی ندارم،
پس نمی‌توانم HTML واقعی صفحات لاگین‌شده را ببینم. تمام معماری، UI، منطق اولویت‌بندی،
ذخیره‌سازی، قفل امنیتی و ارسال پیام **کامل و آماده اجراست**؛ فقط ۴ فایل اسکرپر
(`src/scrapers/*.js`) دارای `TODO` هستند و باید با سلکتورهای واقعی HTML هر سایت
تکمیل شوند. من می‌توانم این بخش را هم برایتان کامل کنم به شرط یکی از این دو:
1. یک نمونه از HTML صفحه لیست پروژه‌ها (بعد از لاگین) را برایم بفرستید (کپی Source صفحه)، یا
2. دسترسی موقت آزمایشی به حساب کاربری بدهید تا ساختار را استخراج کنم.

آدرس دقیق «ایران تندر» و «آرتا پارسیان مازندران» را هم نتوانستم با قطعیت پیدا کنم؛
لطفاً لینک دقیق را بفرستید تا در `src/config/sites.json` ثبت شود.

## آپدیت خودکار
این قابلیت (اپ خودش نسخه جدید رو پیدا و نصب کنه) در نسخه‌های قبلی امتحان شد ولی
Release روی گیت‌هاب به‌درستی منتشر نمی‌شد و باعث سردرگمی می‌شد. فعلاً کنار گذاشته
شده تا روی پایداری خود اپ تمرکز کنیم؛ روش فعلی: هر توسعه جدید → دانلود exe از
Artifacts → نصب دستی (که خودش، چون appId ثابت مونده، به‌صورت آپدیت روی نصب قبلی
می‌شینه، نه نصب از صفر - نیازی به Uninstall نیست).

## ساخت خودکار نصب‌کننده ویندوز بدون هیچ کاری روی سیستم خودتان (روش پیشنهادی)
یک فایل آماده در مسیر `.github/workflows/build-windows.yml` گذاشته شده که کار ساخت exe
را روی سرورهای گیت‌هاب (به‌طور خودکار، بدون نصب هیچ‌چیزی روی سیستم شما) انجام می‌دهد:

۱. یک حساب رایگان در github.com بسازید (اگر ندارید)
۲. یک ریپازیتوری جدید (خصوصی یا عمومی) بسازید
۳. تمام فایل‌های این پوشه (بعد از اکسترکت zip) را با گزینه «Add file → Upload files»
   در مرورگر آپلود و Commit کنید
۴. به تب **Actions** ریپازیتوری بروید؛ ساخت به‌صورت خودکار شروع می‌شود (حدود ۲ تا ۴ دقیقه طول می‌کشد)
۵. وقتی سبز شد، روی همان اجرا کلیک کنید و از بخش **Artifacts** فایل exe نصب‌کننده را دانلود کنید

این تنها راهی است که بدون اینترنت/بیلد روی سیستم شما، یک exe واقعی و تست‌شده تحویل می‌دهد؛
من در این محیط دسترسی به اینترنت ندارم و نمی‌توانم خودم مستقیماً exe بسازم.

## نکته مهم درباره ستاد ایران
این سایت با Puppeteer (مرورگر خودکار واقعی) پایش می‌شود، نه روش ساده HTTP:
- حجم نصب‌کننده به‌خاطر Chromium داخلی Puppeteer حدود ۲۰۰-۳۰۰ مگابایت بزرگ‌تر می‌شود
- اگر صفحه ورود ستاد ایران کد امنیتی تصویری (کپچا) داشته باشد، ورود کاملاً خودکار ممکن نیست؛
  راه‌حل رایج: یک‌بار به‌صورت نیمه‌دستی (با پنجره مرورگر باز، نه headless) وارد شوید و سشن ذخیره بشه
- فیلدهای فرم بر اساس متن لیبل شناسایی می‌شوند (نه id دقیق المان)؛ در اولین اجرای واقعی با حساب شما احتمال نیاز به یک اصلاح کوچک وجود دارد

## نصب و اجرا دستی (روی سیستم خودتان، با اینترنت) - جایگزین روش بالا
```
npm install
npm start
```

## ساخت نصب‌کننده ویندوز (فایل exe)
```
npm run build
```
خروجی در پوشه `dist/` یک فایل نصب‌کننده NSIS برای ویندوز می‌سازد که:
- آیکون دسکتاپ و پنجره را از `assets/icon.ico` می‌گیرد
- در اولین اجرا از کاربر می‌خواهد یک **کد ایمنی (PIN)** تعیین کند؛ در اجراهای بعدی همان کد پرسیده می‌شود

## جایگزینی لوگوی شخصی شما
فایل‌های `assets/logo.png` و `assets/icon.ico` فعلاً یک لوگوی نمونه (موقت) هستند.
لوگوی خودتان را (ترجیحاً PNG مربعی حداقل ۵۱۲×۵۱۲ برای logo.png، و یک .ico واقعی
برای icon.ico) با همین دو نام جایگزین کنید تا هم در برنامه و هم آیکون دسکتاپ نمایش داده شود.

## ساختار پوشه‌ها
```
main.js                 پردازه اصلی Electron - پنجره، قفل امنیتی، IPC
preload.js               پل امن بین رابط کاربری و main
src/config/sites.json    فهرست سایت‌ها، استان‌های هدف، کلیدواژه‌های اولویت
src/scrapers/            یک فایل به‌ازای هر سایت (base.js پایه مشترک است)
src/services/classifier.js   تشخیص اولویت ۱(وافل)/۲(تاپ‌داون)/۳(سایر)
src/ui/                  رابط کاربری (HTML/CSS/JS) با تم تیره
data/                    محل ذخیره محلی (در عمل توسط electron-store در AppData مدیریت می‌شود)
```

## نکات مهم درباره ارسال پیام
- **واتساپ**: از لینک استاندارد `wa.me` استفاده می‌شود که اپ واتساپ را با پیام
  از‌پیش‌نوشته باز می‌کند؛ ارسال نهایی را خودتان با یک کلیک انجام می‌دهید (واتساپ
  اجازه ارسال خودکار بدون تایید کاربر را نمی‌دهد).
- **بله**: بله API عمومیِ «باز کردن چت با شماره دلخواه» ندارد؛ فعلاً فقط اپ/سایت
  بله باز می‌شود. اگر می‌خواهید ارسال به بله هم خودکار شود، باید از سرویس
  رسمی Bale Business API استفاده کنیم که نیاز به توکن/مجوز کسب‌وکاری دارد.

## قدم بعدی پیشنهادی
۱. لینک دقیق ایران تندر و آرتا پارسیان مازندران را بفرستید
۲. یک نمونه HTML از صفحه پروژه‌های سازه جو (بعد از لاگین) بفرستید
۳. لوگوی نهایی را بفرستید
با این سه مورد، اسکرپرها را کامل و واقعی می‌کنم و یک بیلد تست شده می‌سازم.
